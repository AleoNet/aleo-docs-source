# Reference

This is the complete reference for Aleo Instructions — the register-based, statically typed instruction set executed by the Aleo Virtual Machine (AVM).

## Syntax

All operations follow the form:

```aleo
{opcode} {operands} into {destination};
```

```aleo
add r0 r1 into r2;
abs.w r0 into r1;
mul r0 2scalar into r1;
```

Operands are the values passed to operations — registers, literals, and built-in values. All values are stored in numbered registers (`r0`, `r1`, ... `rN`).
