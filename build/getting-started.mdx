# Getting Started

Choose the toolchain that fits your use case:

- **[Leo](/leo/getting_started/installation)** — Write, compile, and deploy Aleo programs using Leo: a high-level language for zero-knowledge applications.

- **[SDK](/build/sdk/getting-started)** — Build JavaScript/TypeScript applications that interact with the Aleo network using the Provable SDK.

- **[Wallet Adapter](/build/wallet-adapter/getting-started)** — Integrate Aleo wallet connectivity into your React frontend.
