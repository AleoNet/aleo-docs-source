# Architecture

The Aleo network is built on two core software components — **snarkVM** and **snarkOS** — that together implement the offchain execution / onchain verification model.

![Architecture Overview](/img/architecture_overview.png)

## snarkVM

**snarkVM** is the core virtual machine for the Aleo network.  It's the offchain execution environment that runs programs and generates zero-knowledge proofs. It has three main components:

- **Synthesizer** — Translates program logic into arithmetic circuits compatible with the Varuna zk-SNARK proof system
- **Algorithms** — Implements the proof system and cryptographic primitives (hashing, encryption, signature schemes)
- **Ledger** — Provides data structures and methods for interacting with blockchain state

When a user executes an Aleo program, snarkVM compiles it into a circuit, runs it with the user's inputs, and produces a ZK-SNARK proof of correct execution. This all happens locally — snarkVM runs on the user's device, not on the blockchain.

## snarkOS

**snarkOS** is the blockchain node software that powers the Aleo network. It verifies proofs generated by snarkVM, runs the AleoBFT consensus protocol, and maintains the distributed ledger.

snarkOS supports three node modes:

| Mode | Role |
|---|---|
| **Validator** | Verifies proofs, produces blocks, participates in consensus |
| **Prover** | Solves puzzles to earn coinbase rewards |
| **Client** | Serves blockchain data and relays transactions |
