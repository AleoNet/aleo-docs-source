# Contributing

Found an error or want to improve these docs? Contributions are welcome.

## Providing Feedback

If you've found an issue or have a suggestion but don't have time to make changes yourself, open an issue:

1. Go to the [Issues](https://github.com/AleoNet/welcome/issues) page.
2. Provide a clear title summarizing the issue or suggestion.
3. For bugs: describe what you expected vs. what you saw, with steps to reproduce.
4. For suggestions: explain your idea and how it would improve the docs.

## Making Changes

1. Fork the [welcome](https://github.com/AleoNet/welcome) repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/welcome.git
   cd welcome/documentation
   ```
3. Create a branch for your changes:
   ```bash
   git checkout -b your-feature-branch
   ```
4. Make your changes. Most content is in Markdown format.
5. Commit with a descriptive message:
   ```bash
   git commit -am "Add description of your changes"
   ```
6. Push and open a Pull Request:
   ```bash
   git push origin your-feature-branch
   ```

## Guidelines

- Write clearly and concisely, following the existing style.
- Use proper Markdown formatting for headings, code blocks, and links.
- Verify all links are correct and working.
- Include images or diagrams where they help illustrate concepts.
